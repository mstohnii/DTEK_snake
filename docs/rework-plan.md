# DTEK_snake — план переробки (v2)

## Мета
Зберегти впізнаваний вигляд «графіка відключень ДТЕК», але:
- прибрати баги та технічний борг;
- розділити код на модулі з чистою, тестованою ігровою логікою;
- додати функції, що підсилюють тему гри та роблять її зручною на телефоні.

Обмеження: статичний сайт без збірки й залежностей (GitHub Pages).

## 1. Баги

## 2. Технічний борг
- Один IIFE з логікою, рендером і вводом → модулі `src/`:
  - `config.js` — константи;
  - `game.js` — чиста логіка (стан, тік, буфер ходів, спавн), ін'єкція RNG для тестів;
  - `input.js` — мапінг клавіш (чиста функція), свайпи, D-pad;
  - `renderer.js` — DOM, будується один раз; оновлюються лише змінені клітинки;
  - `storage.js` — безпечний `localStorage`, міграція старого рекорду;
  - `main.js` — склеювання, цикл `requestAnimationFrame`, UI-стани.
- Перебудова DOM усіх 168 клітинок на кожен тік → дифф-рендер класів.
- JS-синхронізація висоти рядків (`syncSquares`) → одна CSS Grid таблиця + `aspect-ratio`.
- Мертвий код: `clamp`, `pattern-on/off`, `height: 1fr`, `cell-row-end`.
- `HIGHLIGHT_ROW` захардкоджений → підсвічується реальний сьогоднішній день і поточна година.
- Немає тестів і CI → `node --test` (без залежностей) + GitHub Actions.

## 3. Нові функції
1. **Режим «Без стін»** — змійка проходить крізь край поля.
2. **Відключення (перешкоди)** — кожні 4 з'їдені цілі на графіку з'являється 3-годинний блок відключення (вирівняний по 3-годинних роздільниках), в який не можна врізатися. Не спавниться поруч із головою.
3. **«Світло дали!» (бонус)** — іноді з'являється зелена ціль на обмежений час: +3 очки, блимає перед зникненням.
4. **Стани гри**: «Готово» (старт стрілкою — одразу в цьому напрямку), пауза з написом на полі, автопауза при переході на іншу вкладку, Enter — нова гра.
5. **Мобільний D-pad** на сенсорних пристроях + свайпи по всьому полю.
6. **Темна тема** за системними налаштуваннями.
7. **Рекорд для кожного режиму** окремо; налаштування запам'ятовуються.
8. **Доступність**: `aria-live` для рахунку, діалог завершення з фокусом на кнопці.

## 5. v2.1 — складність, теми, таблиця лідерів
- **Рівні складності** (`DIFFICULTIES` у `src/config.js`) замінили перемикачі «Без стін» / «Відключення»: Легкий (прохідні стіни, повільно), Звичайний, Складний, Пекельний. Рівні відрізняються швидкістю, постійними відключеннями, тимчасовими стінами (попередження → суцільна → зникає) та «важким» розміщенням цілей (найважча з N кандидатів, без глухих кутів).
- **Детермінованість:** уся випадковість іде через `mulberry32(seed)`. Однаковий `seed` і однакові натискання дають однакову гру.
- **Таблиця лідерів:** Cloudflare Worker + D1 (`server/`). Сервер видає підписаний квиток із `seed`, а потім сам повторює гру з записаних натискань і зберігає власний підрахунок. Також перевіряються: одноразовість квитка, вік квитка, реальний час гри, ліміт частоти, ім'я.
- **Теми:** `data-theme` на `<html>`, токени кольорів для кожної теми. «Авто» стежить за системною темою; тема застосовується ще до першого малювання сторінки.
- **Тести:** ігрова логіка, складність, повтор (бот грає й перевіряється), API на `node:sqlite` замість D1.
