# DTEK_snake — «Змійка» у стилі графіка відключень ДТЕК

Веб‑гра, що імітує вигляд таблиці відключень ДТЕК: 7 днів × 24 години, вертикальні підписи годин і поділ кожні 3 години. Змійка рухається по «клітинках розкладу», а на складніших рівнях графік заповнюють відключення й тимчасові стіни.

## Живе демо
- [mstohnii.github.io/DTEK_snake](https://mstohnii.github.io/DTEK_snake/)

## Можливості
- **4 рівні складності** (див. таблицю нижче): швидкість, тимчасові стіни, постійні відключення та «важкі» місця для цілей.
- **Онлайн‑таблиця лідерів** для кожного рівня, з перевіркою результату на сервері.
- **6 тем:** Авто, Світла, Темна, «Блекаут», «Ретро LCD», Висока контрастність.
- **«Світло дали!»** — зелений бонус +3, зникає через деякий час.
- Підсвічені **сьогоднішній день** і **поточна година**.
- Буфер ходів: два швидкі повороти поспіль спрацьовують, розворот «у себе» неможливий.
- Автопауза при переході на іншу вкладку; особистий рекорд на кожному рівні.
- **Телефони й планшети:** окремі розкладки для портретної та альбомної орієнтації, свайпи по всьому полю, екранний D‑pad (див. нижче).
- **Встановлення як застосунок і гра без інтернету:** додайте на головний екран, і гра працюватиме навіть під час відключення.

### Телефони й планшети
| Пристрій | Що змінюється |
|---|---|
| Телефон, альбомна орієнтація | Компактна шапка. Поле підганяється під висоту екрана, D‑pad праворуч від поля, усе вміщується без прокрутки. |
| Телефон, портретна орієнтація | D‑pad великими кнопками під полем; підказка повернути телефон, щоб клітинки стали більшими. |
| Планшет | Більші кнопки (зручні цілі ≥44 px), D‑pad під полем. |

Також:
- Свайп можна почати будь‑де над полем, навіть на написі «Проведіть пальцем».
- Під час гри екран не гасне (Wake Lock). Коротка вібрація на бонус і зіткнення (Android).
- Кнопка «⛶» вмикає повноекранний режим (Android, iPad) і, де можливо, фіксує альбомну орієнтацію.
- При повороті пристрою або переході в іншу вкладку гра стає на паузу.
- Враховано вирізи екрана (`safe-area-inset`), iOS не збільшує текст і не масштабує сторінку при фокусі в полі імені.
- Немає «залиплих» hover‑станів після дотику, контекстного меню при довгому натисканні та pull‑to‑refresh під час свайпів.

**Встановлення:** Android Chrome → меню → «Додати на головний екран». iPhone/iPad Safari → «Поділитися» → «На початковий екран». Після першого відкриття гра працює офлайн (service worker `sw.js`). Онлайн‑таблиця лідерів, звісно, потребує інтернету; без нього ігри просто нерейтингові.

### Рівні складності
| | Легкий | Звичайний | Складний | Пекельний |
|---|---|---|---|---|
| Стіни поля | прохідні | смертельні | смертельні | смертельні |
| Швидкість (старт → макс., мс/крок) | 260 → 120 | 240 → 75 | 210 → 65 | 180 → 55 |
| Постійні відключення (3 год) | — | — | кожні 5 цілей | кожні 3 цілі |
| Тимчасові стіни | — | — | до 2, ~кожні 55 кроків | до 4, ~кожні 30 кроків |
| Розміщення цілей | випадкове | випадкове | найважча з 3 | найважча з 6 |

**Тимчасова стіна** спершу блимає пунктиром (через неї ще можна пройти), потім стає суцільною, а згодом зникає. Вона ніколи не з'являється поруч із головою чи просто перед нею й не стає суцільною там, де вже лежить змійка.

**Важке розміщення цілей:** гра бере кілька випадкових вільних клітинок і обирає ту, що далі від голови й ближче до стін та перешкод, але ніколи не глухий кут.

Усі параметри — у `src/config.js` (`DIFFICULTIES`).

## Таблиця лідерів і захист від накруток
Сервер не довіряє рахунку, який надсилає браузер:

1. На початку гри сервер видає **підписаний квиток**: випадковий `seed`, рівень і час видачі (HMAC‑SHA256).
2. Гра повністю детермінована: з того самого `seed` і тих самих натискань виходить та сама гра. Браузер записує лише прийняті повороти: `[крок, напрямок]`.
3. Після гри браузер надсилає квиток, ім'я, натискання й рахунок. Сервер **сам програє всю гру** тим самим кодом (`src/game.js`) і зберігає рахунок, який отримав сам.

Відхиляється:
- підроблений або змінений квиток;
- квиток, використаний вдруге;
- квиток, старший за 6 год;
- змінені натискання (`replay-*`);
- рахунок, що не збігається з повтором;
- гра, «зіграна» швидше, ніж це можливо в реальному часі;
- понад 6 спроб надсилання або 30 квитків за хвилину з однієї IP (ліміт перевіряється атомарно, ще до повтору гри);
- тіло запиту, більше за 256 КБ.

Імена перевіряються: 2–16 літер, цифр, пробілів, `.-_'`.

Чого це не зупиняє: бот, який справді грає в реальному часі. Від цього браузерна гра захиститися не може. Бот, до того ж, знає `seed`, тож може наперед порахувати, де з'являться цілі й стіни. Щоб закрити це повністю, сервер мав би видавати випадковість частинами під час гри, тобто запит на кожну ціль. Для казуальної гри це свідомий компроміс.

## Запуск локально
Гра — статичні файли з ES‑модулями, тож потрібен локальний сервер (не `file://`):

```bash
python -m http.server 5173
```

Локальний API таблиці лідерів працює на Node 22.13+ (`node:sqlite`) без облікового запису Cloudflare. Сторінка на `localhost` підключається до нього сама:

```bash
npm run dev:api
```

## Розгортання таблиці лідерів (Cloudflare Workers + D1)
Код Worker лежить у `server/`. Він імпортує ту саму ігрову логіку з `src/`.

```bash
cd server
npm install
cf d1 create --name dtek-snake-leaderboard
```

1. Впишіть `id` створеної бази в `server/cloudflare.config.ts` (`bindings.d1({ id, name })`).
2. Застосуйте міграції: `cf d1 migrations apply <database-id> --dir migrations`.
3. Створіть файл `.env.production` (його ігнорує git) з рядком `TOKEN_SECRET=<довгий випадковий рядок>`.
4. Розгорніть: `cf deploy --secrets-file .env.production`.
5. Вкажіть URL Worker у `index.html`: `<meta name="leaderboard-api" content="https://…workers.dev">`. Перевірте, що домен сайту є в `ALLOWED_ORIGINS` у `cloudflare.config.ts`.

### API
| Метод | Шлях | Що робить |
|---|---|---|
| `POST` | `/api/runs` `{difficulty}` | видає квиток `{token, seed}` |
| `POST` | `/api/scores` `{token, name, inputs, endTick, score}` | перевіряє повтор і зберігає результат, повертає `{rank}` |
| `GET` | `/api/leaderboard?difficulty=…` | топ‑10 |

## Структура
```
index.html             розмітка
styles.css             стилі: теми (data-theme), адаптив
assets/                іконки (assets/icons — іконки застосунку)
src/config.js          розмір поля, рівні складності, теми
src/game.js            детермінована ігрова логіка (без DOM), спільна з сервером
src/rng.js             генератор випадкових чисел із seed (mulberry32)
src/replay.js          запис натискань і повтор гри для перевірки
src/leaderboard.js     клієнт API таблиці лідерів
src/input.js           клавіатура, свайпи, D-pad
src/renderer.js        побудова сітки й оновлення лише змінених клітинок
src/storage.js         localStorage: налаштування, особисті рекорди
src/device.js          wake lock, вібрація, повний екран, service worker
sw.js                  офлайн‑кеш (network-first)
manifest.webmanifest   встановлення як застосунок
src/main.js            ігровий цикл і UI
server/src/worker.js   API таблиці лідерів (Cloudflare Worker)
server/migrations/     схема D1
server/dev-server.mjs  локальний API на Node
tests/                 тести (node:test), зокрема гри, повтору й API
```
